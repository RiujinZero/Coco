## Best model (20k bodies, the size guideline)

```
ms_babylm DIR 64 10 gpu --epochs N --overlap motifs=1:256,2:4096,3:8192,4:8192 units=21248 ws_mem_in=0 \
    ws_split=1 tiles=3 tile_avg=1 tile_wm=8 tile_att=1
```

- `ws_split=1` (wide readout): each motif's emission is also read through its own readout weights. The summed 32-dim
  workspace was the bottleneck: 1.966 -> 1.916 bits/byte at one epoch with no skill regression.
- `tiles=3 ... tile_att=1` (memory v1, the averaging pyramid + working memory + slot attention): load-bearing on real text,
  long reach, skills up.
- Held-out by epoch: 1.902, 1.830, 1.793, 1.770 (the old 82k model's best: 1.842 after 8 epochs).
- Full sets (BLiMP / supplement / entity): epoch 2 55.07 / 52.98 / 17.86; epoch 4 uninterrupted 53.68 / 53.21 / 17.76.
  BLiMP falls after epoch 2 while loss improves (the model fits the corpus: generation turns fluent, encyclopedic and
  copied). Continuing from epoch 2 with the optimiser RESTARTED (--init) gives the best skills yet at epoch 4:
  **BLiMP 56.06** / 55.02 / 18.24 (same lr, held-out 1.814) and 54.93 / **56.64** / 17.69 (lr x0.3, held-out 1.795).
  A second restart (epochs 5-6) keeps them there: 54.44 / 55.92 / 18.23 and 55.63 / 55.16 / 18.31 (held-out 1.808 / 1.804).
  Periodic restarts are the training schedule to use until the cause is understood.

## Memory (the user's question: working, short, long-term memory without a KV cache)

- Holding works (the pyramid). Retrieval by LEARNED attention never found bound items (it avoided them).
- Retrieval by FIXED context keys works: `tile_ret=N` (episodic buffer of word tiles; keys = frequency-weighted,
  position-coded hashes of the words before each word; `tile_ret_heads=2` adds an order-free head; `tile_ret_recency`,
  `tile_ret_skip` = don't retrieve the cue). Bind-and-recall ~90-97% for 1-4 bindings over 60 filler words (chance 50),
  bounded by the buffer (512 items + recency: 87% at 120 words). Constant cost per byte.
- Not yet useful on tasks: bAbI multiple choice unchanged (~37%), BabyLM skills unchanged. bAbI needs superseding facts
  and knowing which word of a matched sentence answers.
