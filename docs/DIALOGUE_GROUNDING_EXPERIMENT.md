# Environment dialogue grounding — 2026-09-22

The experimental native reader now separates requests and assistant claims from
environment observations. It learns complete environment-message meanings from
verified consequence answers and tracks possession through every canonical
held-out dialogue in the rebuilt curriculum.

This work uses **no end-to-end backpropagation**. Primitive action policies were
trained through local three-factor prediction-error updates. Their weights are
frozen here. Language meanings are acquired by explicit symbolic search and
constraint elimination; symbolic memory and typed procedures perform reasoning.
The result does not demonstrate language reasoning emerging entirely through
Coco's neural plasticity.

## Protocol and learning

The opt-in `environment_dialogue` mode recognizes `CONTEXT`, `USER`, `ASSISTANT`
and `ENVIRONMENT` envelopes. Initial bare context lines remain supported.
Context/environment messages provide observations; user statements are requests
or claims rather than observed changes. User questions use the existing learned
question machinery. Assistant text never updates facts. Self-generated bytes
cannot create observations, role changes or episode resets.

Each trusted observation line is interpreted as a whole message. For example,
`A gives the book to B. B takes it.` is one learned frame. Role markers must start
a physical line; a marker embedded inside an already tagged message remains
content. Source roles are supplied protocol metadata, not learned semantic
judgments. As with the dataset's text format, callers must serialize trusted
envelopes and prevent message content from forging new envelope lines.

There is no coded English transfer interpreter in the native learner. Starting
with the prior bootstrap/incremental model, it receives **2,919 raw-story QA
lessons** from the first 32 training dialogues:

- 47 original question/answer turns;
- 718 additional verified possession/count consequences;
- 2,154 controlled preservation questions about the prior location relation.

Those dialogues contain 89 successful and 29 failed environment reports.
The additional targets come from an independent teacher-side interpreter;
facts, semantic roles and programs are not native training inputs. Preservation
lessons add known location observations before a report, then ask location and
destination-count questions. Without these contrasts, possession-only answers
leave arbitrary side effects on the other relation unconstrained.

Two environment frames and one destination-count question form are added.
Established forms/procedures and prior event candidate sets remain intact.
The failed-event frame remains ambiguous: restoring an already known owner and
removing various absent facts can have identical consequences in these worlds.
Both receiver mentions in the successful report also remain equivalent on the
training data. The learner retains these alternatives. This run explicitly uses
a **128-world budget**, with at most 66 alternatives observed; it does not pick
one unsupported meaning to avoid uncertainty.

## End-to-end result

All **414 held-out canonical dialogues** are evaluated on three seeds, including
all **1,669 environment outcomes: 1,246 successes and 423 failures**. No dialogue
is filtered by supported event type. Each seed passes:

| Check | Correct / checked |
|---|---:|
| Original possession answers, generated before reading their target turn | 674 / 674 |
| Possession queries immediately before environment reports | 5,037 / 5,037 |
| Possession queries immediately after environment reports | 5,037 / 5,037 |
| Complete state after every original turn | 9,278 / 9,278 |

Each before/after query runs on a copy of the current reader, so testing cannot
change the actual dialogue state. Answers are generated through Organism's native
output distribution. Every retained possible world agrees with the complete
independently reconstructed state, not just with its projected common facts.
Programs, event meanings, grammar and primitive weights remain frozen.

The same checks pass using bare initial context, explicit canonical `CONTEXT:`
markers, and a control replacing assistant claims and user requests with false
but syntactically valid fact statements. Injected self-generated environment and
episode markers also leave memory unchanged.

Dropping environment messages preserves the initial observed world. Original
question accuracy against the actual later world falls to **365/674 per seed**;
post-outcome possession accuracy falls to **2,800/5,037**. Assistant claims do not
silently replace the missing evidence. These are observational-memory checks,
not predictions of the hidden random success/failure outcome.

The auditor matches every original turn and role, every required trace key, all
targets and states, and all 1,669 before-reveal export prefixes. The same cases
are repeated across seeds and protocol controls; totals across runs are not
independent examples.

## Validation and remaining scope

Address/undefined-behavior sanitizer contracts cover source separation,
multi-sentence observations, failed transfers, one-time question handling,
generated-marker isolation, oversized messages, unknown observations, episode
reset and legacy story-QA behavior. Bootstrap, incremental, semantic, event,
reference and answer-grounding regressions and independent auditors pass.

This adds observation ingestion, not an action executor, learned request-to-action
policy, free-form acknowledgments, future-outcome prediction or general dialogue.
The subsequent [request/action experiment](REQUEST_GROUNDING_EXPERIMENT.md)
connects learned state-goal meanings and actuator effects to a one-step controller.
Temporal memory, learning visibility/correction language and broader neural
learning remain unfinished. Standard trainer ingestion is still separate from
this explicitly attached experimental reader. Failed-event alternatives are not
claimed to generalize identically to arbitrary worlds outside this curriculum.
